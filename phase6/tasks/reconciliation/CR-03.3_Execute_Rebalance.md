# CR-03.3: Execute Rebalance After Suspension

**Parent:** CR-03  
**Status:** Ready for delegation  
**Priority:** High  
**Depends on:** CR-03.2

## Problem
Rebalance must only run after all conflicting stops have been suspended.

## Desired Behavior
Once active stops are suspended, execute the existing rebalance logic using live balances.

## Scope (In)
- Call existing rebalance logic (`rebalance_plan` + order execution)
- Use live balances (post any prior liquidation)
- Maintain current daily rebalance behavior

## Scope (Out)
- Stop suspension (CR-03.2)
- Re-attaching stops (CR-03.4)

## Success Criteria
- Rebalance executes cleanly after suspension step
- New allocations are calculated and trades are placed
- No interference from old stops

## Validation
- Rebalance completes successfully after suspension
- Portfolio state reflects new allocations

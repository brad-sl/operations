1D %
Whole-account % change vs ~24h ago. Deposit-adjusted (external cash in/out removed). Includes unrealized moves on open positions—not closed-trade PnL alone. Deposit-adjusted wallet return; 3% SL is per-position from entry, not a portfolio DD cap.
--
7D %
Rolling 7-day portfolio return, deposit-adjusted. Early noise window — can look green while the longer path is still repairing. Not the main stabilize gate.
--
14D %
Rolling 14-day deposit-adjusted wallet return. Primary trend-repair gate: claim “stabilizing” only after ~14d of better path — not after one green week. Slow bleed here is common before regime transitions; 7D alone can fool you into quitting right before a turn.
--
30D %
Rolling 30-day portfolio return, deposit-adjusted. Longer context / legacy drawdown. Requires enough snapshot history; shows N/A if the window cannot be computed.
--
Exit WR
Share of recent realizing exits (non-zero PnL in last 100 ledger rows) that won. Count-based—many small wins can read high even when portfolio % is negative. Not the same as 7D/14D %.
